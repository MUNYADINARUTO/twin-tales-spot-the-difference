Twin Tales is a spot-the-difference game: two hand-drawn pictures side by side, a handful of tiny lies between them, and a ticking clock. Five original scenes — Sunny Meadow, Harbor at Dusk, Cozy Kitchen, Enchanted Forest, Starlight Observatory — with 42 differences to find, hints, combos, synthesized sounds and a best score that survives between visits.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play in a desktop browser. No build step, no network requests: the game is plain static files under `game/`.
